# «Поперёк волокон» — авторский медиа-проект су-шефа (v3.2)

**Версия 3.2** · 5 ноября 2026 · **Бренд:** `Поперёк волокон` (`@poperek_volokon`) · **Фирменный вердикт/рубрика:** `«Шеф, у нас отмена!»`

Ироничный, острый и многогранный проект практикующего повара с 10-летним опытом: **изнанка ресторанной кухни со здоровым цеховым юмором, развенчание кулинарных мифов и честная проверка в деле ножей, посуды и инвентаря с маркетплейсов (Ozon, Wildberries, Яндекс Маркет, Авито).**
