# Gastronomy

Ну, начнем.

## Проект

Разработка прототипа российской геймифицированной кулинарной платформы — рабочее название «Кулинарная лига».

**Текущий статус:** исследовательская и продуктовая документация импортирована; следующий этап — совместная проработка и прототипирование. Production-разработка пока не одобрена до проверки спроса и поведения пользователей.

## Продуктовая гипотеза

Не универсальный каталог рецептов, а социальная платформа реальных кулинарных заданий:
- персональные квесты и прогресс;
- тематические кулинарные челленджи;
- добровольные дуэли, команды и соревнования;
- публикация приготовленных блюд и обратная связь;
- сезоны, достижения и награды без pay-to-win.

Ключевой цикл: **задание → выбор блюда → приготовление → подтверждение результата → прогресс/обратная связь → новое задание**.

## Исследовательская база

Документы перенесены из репозитория Market-Research-Opportunity-Lab. Историческое решение NO-GO для первоначальной широкой универсальной FoodTech-платформы сохранено отдельно; новая «Кулинарная лига» — другая, более узкая гипотеза, допущенная только к discovery и пилоту.

## Принципы проекта

1. Основной рынок первого запуска — Россия.
2. Российские продукты и заменители — конкурентное ядро; зарубежные продукты — технологический benchmark, если не доказано их реальное присутствие на рынке РФ.
3. Не смешивать охват, посещения, установки, MAU, платящих пользователей и выручку.
4. Не объявлять спрос подтверждённым без интервью, тестов и наблюдаемого поведения.
5. Сначала проверяем ключевой цикл на прототипе и ручном пилоте; затем принимаем решение о production-разработке.
6. MVP не должен превращаться в комбайн: AI-движок, pantry, meal planning, shopping и marketplace отложены.
7. Участие в публичных рейтингах и соревнованиях добровольное; прогресс должен быть полезен и без публичности.
