# Внешние интеграции и адреса

Инвентаризация выполнена статически по исходникам. Это только список упоминаний hostnames, а не проверка доступности и не подтверждение, что каждый адрес вызывается в runtime. Никакие запросы к перечисленным сервисам не отправлялись.

| Категория | Hostnames, найденные в коде/конфигах | Следующая проверка |
|---|---|---|
| UI/CDN | `cdn-ra3.ragemp.pro`, `cdn.ragemp.pro` | Установить, какие client assets загружаются удалённо; сделать собственный CDN или закрепить разрешённый адрес/контент. Не удалять внешние запросы вслепую. |
| Backend API / cloud | `api.redage.net`, `cloud.redage.net`, `redage.net` | Определить реальные HTTP clients, payload и отправляемые player/server данные; получить owner confirmation или переключить на новый backend. |
| Payments | `pay.redage.net` | Не активировать донат/платёжные кнопки до отдельной проверки callback, получателя и безопасности платёжного потока. |
| Radio/voice | `radio-srv1.11one.ru`, `radio.redage.net` | Установить владельца voice/radio инфраструктуры, лицензию/доступ, конфигурацию и доступность; заменить адреса для собственного сервера, если требуется. |
| Analytics | `www.google-analytics.com`, `www.googletagmanager.com` | Проверить consent/политику данных и удалить или перенастроить чужие analytics IDs. |
| Image upload | `api.imgur.com` | Определить, отправляются ли изображения/пользовательский контент; проверить API credentials и политику хранения. |
| Другие статические ссылки | `forum.redage.net`, `discord.gg`, `sun*-*.userapi.com` | Проверить UI-ссылки/аватарки/объявления и заменить устаревший брендинг/контент.

## Перед staging

- Составить перечень endpoint call sites и формат данных, не записывая токены/подписанные URL в документацию.
- Подменить все owner-specific backend/payment/analytics/voice values на test endpoint или отключённый режим.
- Проверить Network tab/logging только на локальном staging и зафиксировать, что запросы направляются в контролируемые системы.
- Не отправлять production player data на сторонние/старые endpoints во время анализа.
