## Не выводить из этих наблюдений

- Npm audit по свежему разрешению без upstream lock не является точным отчётом о production runtime.
- Неудача из-за отсутствующих файлов/лимита памяти не доказывает, что исходный полный build сломан.
- Два невалидных JS-файла пока не доказывают дефект живого сервера, так как они не импортируются известными entry points.
