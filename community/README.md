# Поперёк волокон — редакция сообщества ВК

Отдельное направление внутри репозитория Gastronomy. Папка Recipes остаётся самостоятельной базой рецептов и не смешивается с редакционными материалами сообщества.

## Задача
Вести небольшое живое кулинарное сообщество: делиться полезными знаниями о продуктах, кухонными приёмами, рецептами и наблюдениями. Подача — журнальная, с характером печатных изданий 1950–60-х, но без выдуманной исторической атрибутики.

## Основное правило
Номер публикации — сквозной редакционный идентификатор. Даты указываются только реальные и только если полезны читателю. Не придумывать годы, даты, номера выпусков и псевдоархивные отметки.
