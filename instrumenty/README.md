# Локальные инструменты редактора

Python 3.11+, без установки пакетов и без отправки данных в интернет. Выполнять из корня репозитория:

```sh
python3 instrumenty/proverit.py text путь/к/тексту.md
python3 instrumenty/proverit.py png путь/к/картинке.png путь/к/другой.png
python3 -m unittest discover -s instrumenty/tests -v
```

`text` выдаёт **подсказки для ручной проверки**, а не оценку ИИ или качества: несколько запрещённых пользователем слов, отдельные обороты, технические пометки и возможные контакты. Совпадение может быть безобидным; отсутствие совпадений ничего не гарантирует. Инструмент не определяет смысл, факты, авторство, биографию, рекламную маркировку или права на изображения. Для защиты анонимности он не выводит найденные адреса и телефоны, только номер строки и категорию; автоматическая проверка также пропустит многие персональные данные.

`png` читает заголовок PNG, сообщает размер, вес и идентичные файлы по SHA-256. Это не декодирование и не проверка целостности, читабельности, контраста, авторских прав, геометрии или отображения ВК. Не конвертирует и не перезаписывает файлы. JPEG и другие форматы эта проверка не принимает. Код завершения 1 означает ошибку чтения файла, а не плохое качество; подсказки к тексту не считаются ошибкой.

Сборка существующих карточек отдельно использует Pillow и DejaVu. Для изолированной установки: `python3 -m venv .venv`, затем `.venv/bin/pip install -r instrumenty/requirements-grafika.txt`; сборщики запускать через `.venv/bin/python`. Скрипты ожидают DejaVu в `/usr/share/fonts/truetype/dejavu/`; на других системах путь может потребовать изменения. Не редактируйте завершённый пост без согласования. Генерация ИИ-иллюстраций в этих скриптах не предусмотрена.
