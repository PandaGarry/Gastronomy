# Локальные инструменты редактора

Проверки `proverit.py` работают на Python 3.11+ без установки пакетов и без отправки данных в интернет. Выполнять из корня репозитория:

```sh
python3 instrumenty/proverit.py text путь/к/тексту.md
python3 instrumenty/proverit.py png путь/к/картинке.png путь/к/другой.png
python3 -m unittest discover -s instrumenty/tests -v
```

`text` выдаёт **подсказки для ручной проверки**, а не оценку ИИ или качества: несколько запрещённых пользователем слов, отдельные обороты, технические пометки и возможные контакты. Совпадение может быть безобидным; отсутствие совпадений ничего не гарантирует. Инструмент не определяет смысл, факты, авторство, биографию, рекламную маркировку или права на изображения. Для защиты анонимности он не выводит найденные адреса и телефоны, только номер строки и категорию; автоматическая проверка также пропустит многие персональные данные.

`png` проверяет сигнатуру, структуру блоков и контрольные суммы CRC, сообщает размер, вес и идентичные файлы по SHA-256. Он не декодирует пиксели и потому не гарантирует полную корректность изображения; также не проверяет читабельность, контраст, авторские права, геометрию или отображение ВК. Не конвертирует и не перезаписывает файлы. JPEG и другие форматы эта проверка не принимает. Код завершения 1 означает ошибку чтения файла, а не плохое качество; подсказки к тексту не считаются ошибкой.

Сборка существующих карточек отдельно использует Pillow и DejaVu. Для изолированной установки: `python3 -m venv .venv`, затем `.venv/bin/pip install -r instrumenty/requirements-grafika.txt`; сборщики запускать через `.venv/bin/python`. Скрипты ожидают DejaVu в `/usr/share/fonts/truetype/dejavu/`; на других системах путь может потребовать изменения. Не редактируйте завершённый пост без согласования. Генерация ИИ-иллюстраций в этих скриптах не предусмотрена.

## Разделение конкретного PDF с ТТК

Для `razdelit_ttk.py` нужна отдельная зависимость PyMuPDF (проверено на 2.1; лицензия AGPL или коммерческая):

```sh
python3 -m venv .venv
.venv/bin/pip install 'PyMuPDF==2.1'
.venv/bin/python instrumenty/razdelit_ttk.py 'Recipes/Все меню.pdf' 'путь/к/новой-папке'
.venv/bin/python -m unittest discover -s instrumenty/tests -v
```

Скрипт рассчитан на конкретный формат карт: одна страница — одна карта с распознаваемым заголовком, в конце может быть визуально белая пустая страница. Если границы неясны или номер повторяется, останавливается вместо предположений. Для каждого нового PDF сверяет извлечённый текст и изображение с исходной страницей, допускает небольшую разницу округления при отрисовке, создаёт CSV-указатель и отчёт с SHA-256 источника. Существующую целевую папку не перезаписывает. Это проверка разбиения, **не** проверка рецептов и **не** удаление личных данных или названий заведений. Для другого PDF сначала проверить структуру, а не предполагать, что разбиение применимо.
