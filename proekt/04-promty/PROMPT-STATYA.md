# ПРОМПТ 1: История / Анти-миф из голосовой расшифровки (Дзен + ВК Статья)

```
Ты — опытный литературный редактор авторского проекта «Поперёк волокон».
Я — анонимный практикующий су-шеф с 10-летним стажем на кухне.

Ниже — сырая расшифровка моего голосового рассказа (мои факты, детали и наблюдения):
[ВСТАВИТЬ РАСШИФРОВКУ ГОЛОСОВОГО ИЛИ СПИСОК ФАКТОВ]

Задача — собрать плотную, острую статью на 900–1 400 слов для Дзена и ВК.
Рубрика: [За дверью кухни / Шеф, у нас отмена! / Поперёк мифов / Чек с раздачи]
Тема: [ТЕМА]

ТРЕБОВАНИЯ К СТИЛЮ:
- Сохрани мою живую разговорную речь, иронию и здоровый цеховой сарказм.
- Никакого токсичного нытья, пафоса и канцелярита.
- ЗАПРЕЩЕНЫ штампы: «следует отметить», «немаловажно», «на сегодняшний день»,
  «в мире гастрономии», «симфония вкуса», «эмоции», «кулинарная магия», «таким образом».
- НЕ выдумывай факты. Если где-то просится конкретная цифра или цеховая деталь —
  поставь маркер [ВСТАВИТЬ СВОЮ ДЕТАЛЬ: ...].
- 100% анонимность: никаких названий заведений, имён и городов.

СТРУКТУРА:
1. Холодный старт со сцены или саркастичной подколки с первой строки (2 коротких абзаца).
2. Конфликт / в чём подвох (1–2 абзаца).
3. 3–4 плотных блока с цепляющими H2 (абзацы по 2–4 предложения).
4. Нативная врезка под перелинковку: [ССЫЛКА НА ПРОШЛЫЙ ВЫПУСК].
5. Хлёсткий финал + вопрос читателям, провоцирующий спор в комментариях.

После текста дай 5 вариантов заголовка по формуле:
конкретика + цифра/деталь + конфликт/ирония (без пустого кликбейта).
```

# ПРОМПТ 2: Честный обзор товара / Шопс ВК («Проверка в деле»)

```
Я — анонимный су-шеф (10 лет на кухне), автор проекта «Поперёк волокон».
Пишу честный ироничный обзор кухонного инвентаря и посуды с оценкой по нашей фирменной «Шкале цеха»:
- 🔪 «Живёт в скрутке» — уровень профкухни, брать смело.
- 🍳 «Домой — огонь, в цеху умрёт» — честный рабочий вариант для дома.
- 🚨 «Шеф, у нас отмена!» — переоценённый хлам, экономим деньги подписчиков.

Товар: [НАЗВАНИЕ И ХАРАКТЕРИСТИКИ]
Площадка: [ВК Шопс Ozon / Пост в ТГ под WB или Яндекс Маркет / Статья в Дзен]
Мои реальные впечатления от предмета:
[МАТЕРИАЛ/СТАЛЬ, КАК В РУКЕ И В ДЕЛЕ, РЕАЛЬНЫЙ НЮАНС ИЛИ МИНУС, КАКОЙ ВЕРДИКТ СТАВИМ]

Сделай 2 формата:
1. Пост / текст Шопса ВК (800–1 500 знаков):
   - Первая фраза бьёт по типичной боли или маркетинговой сказке с цеховым сарказмом.
   - Разбор по делу глазами повара (баланс, толщина, сталь, удобство ухода).
   - Один честный нюанс/ограничение (чтобы тексту верили на 100%).
   - Финальный приговор строго по «Шкале цеха».
   - ВАЖНО: если это ВК Шопс Ozon — НЕ упоминай другие маркетплейсы.

2. Раскадровка вертикального ролика 20–30 сек (съёмка дома на нейтральном столе,
   в кадре только руки, доска/плита и предмет, без лица):
   - 0–2 сек: жёсткий визуальный и текстовый хук на экране.
   - 3–22 сек: 3–4 коротких кадра проверки в деле + текст субтитров.
   - 23–30 сек: штамп вердикта по «Шкале цеха» + байт на комментарии.
```

# ПРОМПТ 3: Клип-сторителлинг без лица (10–15 сек под удержание >100%)

```
Я — су-шеф, автор канала «Поперёк волокон». Делаю клип на 10–12 секунд для ВК Клипов:
на фоне домашний макро-кадр (руки правят нож о мусат / режут продукт поперёк волокон /
разогревают стальную сковороду), поверх — плотная история с сарказмом на 65–90 слов.

Случай с кухни: [КОРОТКО ОПИСАТЬ СИТУАЦИЮ]

Дай:
1. Верхнюю плашку-крючок (до 5 слов, читается за 0,5 сек).
2. Текст истории по центру экрана (короткие рубленые строки, ироничная концовка).
3. Какой именно кадр рук на столе лучше всего сыграет на контрасте с текстом.
4. Короткую подпись под клипом с вопросом для спора в комментариях.
```
