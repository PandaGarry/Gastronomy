# Мастерская оформления

Запуск из корня репозитория: `python3 redaktor/server.py`, затем открыть `http://localhost:8000/` в браузере. Не открывайте `index.html` через `file://`: браузер может запретить экспорт изображений. Все изображения обрабатываются в браузере; сервер нужен только для раздачи файлов.

Выберите «Обложка ВК» или «Карточка поста», основу, впишите текст, при желании добавьте фото. Текст и фото перетаскиваются на холсте. Скачанный PNG не включает направляющие. Обложка — 1920×768, карточка — 1024×1024. Выбранная основа обложки уже содержит надписи: очистите поле текста, чтобы не накладывать дублирующую надпись. Для нового текста загрузите свою основу без надписей.

Телефонный аватар и обрезка компьютера в предпросмотре — приблизительные модели по предоставленным скриншотам, не официальная спецификация ВК и не гарантия отображения на всех устройствах. Всегда проверять итог в ВК. Редактор не хранит проект после перезагрузки, не умеет исправлять надписи, запечённые в существующей картинке, и не создаёт полноценную ТТК. Длинные строки без пробелов и плотные таблицы требуют ручной проверки. Фотографии и шрифты должны быть пригодны к публикации.
